## 使い方

1. エクスプローラーまたは Finder でファイルを 1 つ以上選びます。
2. **Ctrl + Alt + C**（Mac では **⌘ + ⌥ + C**）を押します。
3. カーソルのそばに小さなメニューが出るので、したいことを選びます。

結果は元のファイルの隣に新しい名前で保存されます。元のファイルはそのままです。

## できること

- **動画を収まるサイズに縮める。** Discord やメール、好きな上限に合わせて：8、10、25、50 MB など。
- **形式を変える。** 動画、音楽、写真、PDF、電子書籍。iPhone の写真（HEIC）を JPG に、ボイスメッセージを MP3 に、動画を GIF に、など。
- **ちょっとした修正。** 写真の回転・反転、位置情報の削除、動画のカット、音声の削除、早送り、静止画の切り出し。
- **PDF。** 複数を 1 つに結合、ページごとに分割、ページを画像に、ファイルを軽く。
- **たくさんのファイルを一度に。** フォルダごと選んでも大丈夫：数件ずつ順番に処理します。
- **そのままチャットへ。** 終わったら「コピー」を押して、Telegram や Discord などで Ctrl + V。
- **スクリーンショットも。** スクリーンショットをコピーしてショートカットを押せば、ファイルとして保存したりそのまま変換したりできます。
- **自分だけのショートカット。** どの操作にも専用のキーを割り当てたり、いくつかの操作を 1 つにまとめたり（「音声を削除して 8 MB に縮める」）。

Word、Excel、PowerPoint のファイルには対応していません。

## インストール

[最新リリース](https://github.com/Dec3n7/mutabor/releases/latest)を開き、お使いのコンピューター用のファイルをダウンロードしてください：

| お使いのコンピューター | ダウンロードするファイル |
| --- | --- |
| Windows 10 または 11 | `Mutabor_…_x64-setup.exe` |
| Apple チップの Mac（M1 以降） | `Mutabor_…_aarch64.dmg` |
| Intel プロセッサの Mac | `Mutabor_…_x64.dmg` |
| Linux | `Mutabor_…_amd64.AppImage` |

インストール後、Mutabor はタスクトレイ（Mac では画面上部のメニューバー）に静かに常駐します。開くウィンドウはありません：ファイルを選んでショートカットを押すだけです。

### 「Windows によって PC が保護されました」「開けません」と出たら

新しい無料アプリではよくあることです。まだコード署名証明書を購入していないため、システムが発行元を確認できないのです。

- **Windows：** **詳細情報** をクリックし、**実行** をクリックします。
- **Mac：** **システム設定 → プライバシーとセキュリティ** を開き、下にスクロールして **このまま開く** をクリックします。

## 安全ですか？

- **ファイルはあなたのコンピューターから出ません。** アップロードもアカウントもトラッキングもありません。
- **追加コンポーネントは頼んだときだけ。** 一部の PDF や電子書籍の操作には無料の追加コンポーネントが必要です。Mutabor はそのサイズを表示し、同意したときだけダウンロードします。
- **さりげないアップデート確認。** 新しいバージョンが出たらお知らせできるよう、Mutabor は 1 日 1 回 GitHub に最新バージョンの番号を問い合わせます。設定でオフにできます。
- **すべて公開。** ソースコードはすべてこのリポジトリにあり、インストーラーは誰かの PC ではなく GitHub 上で公開ビルドされています。

## 知っておくと便利

- 操作の上で **Shift + Enter** を押すと、品質・サイズ・時間範囲などの設定を変えられます。
- **設定** はトレイアイコンのメニューから：ショートカット、言語、同時に処理するファイル数などを変更できます。
- 13 の言語に対応し、システムの言語に自動で合わせます。
- **Mac では** コピーしたスクリーンショットと PDF の操作がまだ使えません。**Linux では** メニューが選択したファイルをまだ認識できないため、今のところ上級者向けです。
